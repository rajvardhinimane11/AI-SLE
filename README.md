## Problem Statement

The 8-Puzzle is a classic Artificial Intelligence search problem consisting of eight numbered tiles and one blank space arranged in a 3×3 grid.

The objective is to move the tiles from a given initial configuration to a specified goal configuration.

This project compares Breadth-First Search (BFS) and Depth-First Search (DFS) for solving the 8-Puzzle problem.

Both algorithms are tested using the same puzzle configurations.

---

## Algorithms Profiled

### Breadth-First Search (BFS)

BFS explores states level by level using a queue.

### Depth-First Search (DFS)

DFS explores one branch deeply before backtracking and uses a stack.
